# 开发任务与依赖

开发者将每项状态和证据填写到 PROGRESS.md。验收优先于任务勾选。

| ID | 依赖 | 实施内容 | 交付证据 |
|---|---|---|---|
| P01 | 无 | npm 工程、strict TS、测试、构建、配置和运行入口 | clean install / typecheck / build |
| P02 | P01 | schema、Clock、事件、ID、错误及能力合同 | schema 与版本/未知状态测试 |
| P03 | P02 | FakeClientBridge、虚拟调度、故障注入、小地图/UI/物品 | 可重复 scenario fixture |
| P04 | P02,P03 | World State 单写者、快照、来源/缺口、查询投影 | 状态隔离和失效测试 |
| P05 | P02 | SQLite 迁移、目标/执行/效果/事件存储 | 真 SQLite 重开与事务测试 |
| P06 | P03,P04,P05 | Executor、Arbiter、Gateway、TTL、取消、效果核对 | 过期、抢占、重试、崩溃窗口测试 |
| P07 | P06 | 最小技能与已知图 A*、进展与重规划预算 | 正常和受阻场景，不只 happy path |
| P08 | P02 | 两个模型适配器、scripted provider、流式解析 | 请求与响应 fixtures、取消/错误测试 |
| P09 | P04,P06,P07,P08 | 工具 schema/router、多轮循环、目标管理 | 模型工具调用到状态变化的端到端测试 |
| P10 | P05,P06,P09 | 重启恢复、未决效果调和、控制台改向 | 冷启动读取 SQLite 的恢复测试 |
| P11 | P07,P09,P10 | demo、诊断、限额、脱敏、离线网络封锁 | 完整验收集和命令输出 |
| P12 | 全部 | README、配置、已知限制、交付报告 | 所有命令可重跑，报告无虚构结果 |

## 禁止的捷径

- P05 不能只 mock 数据库；至少有真实 SQLite 临时文件重开测试。
- P08 不能只有一个接口和返回固定文本的假实现；两个协议的编码/解析代码都需完成。
- P09 不得在 fake model 中直接调用业务函数绕过工具路由。
- P10 不得只 serialize 一个 JSON 对象模拟进程恢复；需重新构造 Runtime，读取磁盘状态。
- P11 不把真实网络测试 skip 后称作全部功能已验证；本阶段不创建依赖真实服务器的验收项。
- 不为“高级扩展”提前实现训练、任意代码执行或完整插件 OS。

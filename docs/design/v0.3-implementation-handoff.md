## 3. 实现约定与迁移落点

- 现src/bridge/version-profile.ts改为版本选择facade；移除release literal作为全工程通用schema的限制。新registry放src/compat/，仅composition与compat实现可导入具体版本。现manifest工具升级v2并给v1显式候选转换器，避免两个注册中心。
- 通用Clock/Evidence/ExecutionContext放src/contracts；时间域不得通过number相同就互换。现BodyContext只在legacy/adapter映射，不让Router自行猜scope。
- src/execution/admission.ts收敛为ControlAuthority及前提求值facade；ActionGateway与EffectCoordinator放同execution目录；Executor仍负责租约与execution状态，不新建第二执行循环。
- SQLiteStore保留低层CAS与事务，业务迁移只能经coordinator；更新调用方返回穷尽union，严禁静默ignore冲突。诊断用readonly store工厂，不调用migrate。
- SkillContext移除bridge写权限；所有技能含chat/UI控制经gateway。只读observe/wait可不准备效果；remember/revise/cancel属于控制写，不借OS输入租约但需scope/revision/generation准入。
- 输入pulse与effect不同：不要求每20Hz同步落库，不允许无primitive屏障派发；聚合运行尾部不确定如实ambiguous。
- helper PS文件保留路径用于打包，C#独立源码与hash列入artifact。源码统一LF、UTF-8，hash针对仓库原始字节；发布后再验安装字节，不任意规范化实际可执行artifact绕过完整性。
- 静态依赖检查解析TS导入图（TypeScript compiler API已存在），限制具体version/driver/store writer进入业务层；禁测试仅搜索固定字符串冒充导入边界。

v0.3新设计入口在对应实现迁移后切换CLAUDE/AGENTS/README，未迁移前注明目标设计，不把旧状态表批量改done。旧文档移历史不删证据；历史数字测试结果附原commit，不覆盖成新结果。
